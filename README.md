# Y8960 MML Helper

Y8960 カートリッジの MML（`.mml`）を書くための VS Code 拡張。

- `.mml` の構文強調
- `y8mmlc` でのコンパイルと、誤りの一覧・該当行へのジャンプ
- できたシーケンスを `y8960player` で鳴らす

コンパイラとプレイヤーは同梱していない。別に用意する。

## インストール

[リリース](https://github.com/madscient/Y8960MML_vscode/releases)から `.vsix` を
落とし、VS Code の拡張機能ビューの「…」メニューから「VSIX からのインストール...」を
選ぶ。コマンドラインなら `code --install-extension y8960mml-helper-<版>.vsix`。

## 用意するもの

| | 入手先 |
|---|---|
| `y8mmlc`（MML コンパイラ） | [Y8960MMLCompiler のリリース](https://github.com/madscient/Y8960MMLCompiler/releases) |
| `y8960player`（プレイヤー） | [Y8960Sequencer のリリース](https://github.com/madscient/Y8960Sequencer/releases) |

Windows 版はどちらも zip で配られている。展開したフォルダの中身はそのまま使う。
`y8960player` は、同じフォルダにあるエミュレータの DLL 3本と一緒に動く。

PATH の通ったところに置くか、設定でパスを指定する。設定に相対パスを書くと、
ワークスペースのフォルダから数える。見つからないときに出る
エラーの「設定を開く」から、その設定へ行ける。

## MML の書き方

- [MML ソースファイルの書き方](https://github.com/madscient/Y8960MMLCompiler/blob/master/doc/mml-source.md)
  ―― トラック行、`#assign` などのメタコマンド
- [MML のコマンド](https://github.com/madscient/Y8960MMLCompiler/blob/master/doc/mml-reference.md)

コンパイラの zip には、例（`examples/demo.mml`）と ADPCM のサンプル
（`presets/`）も入っている。

## 使い方

`.mml` を開き、コマンドパレット（Ctrl+Shift+P）から実行する。

| コマンド | |
|---|---|
| Y8960 MML: コンパイル | 保存してから `y8mmlc` にかける。誤りは「問題」パネルと波線で示す |
| Y8960 MML: コンパイルして再生 | コンパイルが通れば `y8960player` で鳴らす |
| Y8960 MML: パートを選んで再生 | `#assign` のあるトラックの一覧から鳴らすものを選んで再生する。選んだものは、同じファイルで次にこのコマンドを使うときの初期値になる（VS Code を閉じるまで） |
| Y8960 MML: 再生を止める | ステータスバーの「Y8960 再生中」を押しても止まる |
| Y8960 MML: トラックを複製 | 選んだトラックの MML の行を、別のトラックの名前で写す |
| Y8960 MML: トラックを改名 | 選んだトラックの `#assign` と MML の行を、別のトラックの名前にする |
| Y8960 MML: トラックを削除 | 選んだトラックの `#assign` と MML の行を消す |
| Y8960 MML: 選択範囲をタイ・レガートで繋ぐ | 選んだ範囲の音符を `&` で繋ぐ |
| Y8960 MML: 選択範囲をポルタメントで繋ぐ | 選んだ範囲の音符を `~` で繋ぐ |
| Y8960 MML: 選択範囲のタイ・レガートを外す | 選んだ範囲の `&` を消す |
| Y8960 MML: 選択範囲のポルタメントを外す | 選んだ範囲の `~` を、付けた数ごと消す |

後ろの7つは編集するだけで、保存もコンパイルもしない。Ctrl+Z で元に戻る。

- 複製先・改名先に選べるのは、`#assign` も MML の行も無い**空いているトラック**だけ
- **複製では `#assign` を写さない。** 1つのチャンネルを鳴らせるのは1トラックだけで、
  割り当てをそのまま写すとコンパイルが通らない。複製先の `#assign` は自分で書く
- 削除は、消す行の数を出して確かめてから消す

繋ぐ・外すについて。

- MML では**タイとレガートはどちらも `&`**。前後の高さが同じならタイ、違えば
  レガートになる。書き分けるものではない
- `&` は音符と音符の間に、`~` は次の音符の前に入る。どちらも**繋ぐ先の音符の直前**に書く
- **繋がりは切れる** ―― 休符、`@W`、`X名前;`、ブロック（`[1` … `]`）、`(DC)` などの記号。
  そこを境に、前の音符と次の音符は続けて鳴らないため
- すでに `&` か `~` で繋がっている組はそのままにする。付け替えるときは一度外す
- リズムのトラック（チャンネル 10）には `&` も `~` も無いので、選んでも書かない

`y8mmlc` は1回の実行で全部の誤りを出すとは限らない。前半に誤りがあると後半を
見ずに終わるので、直してコンパイルし直すと次の誤りが出ることがある。

`y8mmlc` の出力は「出力」パネルの「Y8960 MML」に出る。

## 設定

| 設定 | 既定 | |
|---|---|---|
| `y8960mml.compilerPath` | `y8mmlc` | `y8mmlc` の実行ファイル |
| `y8960mml.playerPath` | `y8960player` | `y8960player` の実行ファイル |
| `y8960mml.compileOnSave` | `false` | 保存するたびにコンパイルする |
| `y8960mml.outDir` | 空 | `.SQ`・`.PC` を書き出すフォルダ。空ならソースと同じフォルダ。相対パスはソースのフォルダから数える。無ければ作る |
| `y8960mml.playerTick` | 空 | 演奏を進める割り込みの周期。`0` 約60Hz、`1` 約100Hz、`2` 約200Hz。空なら `y8960player` の既定 |
| `y8960mml.playerRepeat` | 空 | 曲を鳴らす回数。`0` は止めるまで繰り返す。空なら1回 |
| `y8960mml.playerMute` | `[]` | 黙らせるもの。例：`["D"]` はトラック D を、`["!A", "!B"]` は A と B 以外を黙らせる。トラック（`A`-`P`）のほか、チップ（`SCC` など）やチャンネル（`OPL2EX1,9` など）も書ける。「パートを選んで再生」では使わない |
| `y8960mml.detectFromContent` | `true` | 下記 |

## ほかの MML 拡張と一緒に使う

`.mml` を別の言語として登録する拡張と一緒に入れると、どちらの言語で開くかは
VS Code が決める。この拡張は、`mml` という言語で開かれたファイルに
`#assign A OPL2EX1 0` のような行があれば Y8960 MML に切り替える
（`y8960mml.detectFromContent`）。

それでも違う言語で開かれたときは、ステータスバーの言語名を押して
「Y8960 MML」を選ぶ。いつも Y8960 MML で開きたいフォルダでは、設定の
`files.associations` に `"*.mml": "y8960mml"` と書く。

## 制限

- 再生中の位置をエディタで示す機能は無い
